## SIFT

### What it does (purpose of the algorithm)
The SIFT Algorithm detects features in a picture. As from its name, it is stable under scaling changes, but also rotation and viewpoing.

### Why (reasons, interest of the feature)
Feature detection allow object detection, for example to identify the contents of a picture. It also allow to match the same object in different pictures to recreate a trajectory in a temporal dimension, or identify some camera transformations.

### How (internal working of the algorithm)
The algorithm relies on a feature detection on the target image at multiple scales.
First, keypoints candidates are obtained from a set of gaussian blurred versions of the image.
Then the candidates are sorted and instable/weak keypoints are removed.
Each keypoint is then assigned a direction.
Finally, a finer description of the keypoint is generated by providing some informations describing the corresponding feature:
- 16×16 neighborhood around the keypoint is selected.
- The neighborhood is divided into sixteen 4×4 subregions.
- An 8-bin orientation histogram is computed for each subregion.
- The resulting 128-dimensional descriptor uniquely represents the keypoint.
